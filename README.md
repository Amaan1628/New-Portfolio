# Syed Amaan Ali — Personal portfolio

A local, single-page React portfolio built with Vite. No backend or account is required.

## Run

```sh
npm install
npm run dev
```

## Production preview

```sh
npm run build
npm run preview
```

Content and role details are in `src/main.jsx`. Design tokens and responsive layouts are in `src/styles.css`. The original résumé is copied to `public/Syed-Amaan-Ali-Resume.pdf`. Fonts are hosted locally.

The two project slots are explicitly labeled placeholders and should be replaced with real projects before a public launch.
